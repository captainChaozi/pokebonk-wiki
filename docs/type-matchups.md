# PokéBonk type matchups: a quick reference

Notes I keep while maintaining the [type chart tool](https://pokebonk.info/tools/type-chart/) on my unofficial PokéBonk fan wiki, [BonkDex](https://pokebonk.info/).

PokéBonk (pokebonk.com, by Charcher) is a free Megabonk-style 3D roguelike that runs in the browser. Season 2 runs from October 22 to November 5, 2026. It is a different game from Touchzada's project at pokebonk.solais.cloud.

- Bulbasaur is the Grass-type starter, Charmander the Fire-type starter and Squirtle the Water-type starter.
- Check each matchup in the type chart rather than relying on a rule of thumb.

Use the [Pokédex](https://pokebonk.info/pokedex/) to look up each Pokémon's typing, then plan four moves in the [build planner](https://pokebonk.info/tools/build-planner/).
