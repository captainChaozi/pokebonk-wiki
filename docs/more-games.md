# More free browser games by Chaozi

Besides [BonkDex](https://pokebonk.info/), I make these small free browser games:

- [Noillirk](https://noillirk.pro/) - a party game about guessing what the crowd answered.
- [Farflung](https://farflunggame.fun/) - a daily geography puzzle with clues and a map pin.
- [Daily Red](https://daily-red.app/) - a daily Pokémon-themed challenge against one fixed opponent.
- [2 Minute Drill](https://2mindrillgame.org/) - a football strategy game about the last two minutes.
- [Plain Game](https://plaingame.fun/) - a free daily estimation game: seven rounds naming things close to a target or estimating a fact. Independent edition, not affiliated with playplain.app.

Disclosure: I'm the developer of all of these. They are fan/indie projects, not official Nintendo or NFL products.
