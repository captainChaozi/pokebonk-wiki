# PokéBonk 状态效果速查（Status effects）

> 整理自非官方粉丝 wiki [pokebonk.info](https://pokebonk.info/) 的 [机制指南](https://pokebonk.info/guides/mechanics/)，对应游戏版本 0.8.77，2026-11-03 核对。本 wiki 只覆盖 pokebonk.com（作者 Charcher）这款游戏。

大多数状态由单一属性的招式施加；状态几率属性会提高触发概率（每次命中不超过 100%）。

| 状态 | 施加属性 | 效果 |
|---|---|---|
| Burned 灼伤 | Fire | 3 秒内再造成触发伤害 30% 的持续伤害 |
| Poisoned 中毒 | Poison | 5 秒持续伤害，最多 10 层；期间无法回血 |
| Paralyzed 麻痹 | Electric | 3 秒半速，偶尔完全停住 |
| Frozen 冰冻 | Ice | 3 层冰寒冻结 1.6 秒（受伤 +20%）；Wet 目标一次冰击即冻 |
| Asleep 睡眠 | — | 停止 3 秒；下一击 ×1.8 并唤醒 |
| Confused 混乱 | Psychic | 3 秒乱走乱打，可能误伤其他敌人 |
| Wet 潮湿 | Water | 持续 5 秒；可触发 Electrocuted 和瞬间冰冻 |
| Cursed 诅咒 | Ghost | 4 秒内所受一切伤害 +25% |
| Heal Block 封疗 | Dark | 6 秒无法回血、护盾减半 |
| Charmed 魅惑 | Fairy | 3 秒伤害 −40%；普通敌人停止攻击 |
| Rooted 束缚 | Grass | 2 秒减速 65% |
| Stunned 眩晕 | Rock | 定身 0.5 秒 |
| Knockback 击退 | Fighting | 比普通命中飞得更远 |

## 用法提示

- 状态本身是“铺垫”，配合对应属性命中会触发元素反应（如 Wet + Electric = Electrocuted ×1.5，Frozen + Rock = Wreckage ×2.6）。
- 属性克制见 [属性页](https://pokebonk.info/types/)。
