# PokéBonk co-op reference

Summary of the [co-op guide](https://pokebonk.info/guides/co-op/) on the unofficial [PokéBonk Wiki](https://pokebonk.info/). Client 0.8.76, checked 2026-10-29. Co-op is live and labelled BETA in the menu. The game is free at pokebonk.com.

## Basics

| Item | Detail |
|---|---|
| Players | 2 to 4 trainers |
| Modes | Classic; Team Survival since 0.8.68 |
| Account | Required since 0.8.73 (guests can upgrade without losing progress) |
| Room code | 4 letters or numbers (not the XXXX-XXXX account invite code) |
| Matchmaking | Find a match (0.8.73): mode, Duo/Trio/Squad, map, difficulty or "Any"; region first |
| Maps offered | Only maps and difficulties every member has unlocked |

## Rules that differ from solo

| Rule | Detail |
|---|---|
| Revive | Hold E next to a downed teammate |
| Spectate | Space switches teammate |
| Targeting | Enemies target the nearest trainer |
| Altars | Shared |
| Captures | Each player throws their own ball |
| Portal | Everyone must stand on it |
| Ping wheel | Hold G (L3 on controller), 8 pings |
| Level-up choice | 5 s per level, up to 10 s, timer does not refill |
| Bag | Usable in co-op (0.8.60); only spent if the run starts |
| Shiny legendaries | Count for the whole team |
| Daily Mutation | Not playable in co-op |

## Team Survival

- A shared boss every 4 minutes, then the Cataclysm and Apocalypse phases.
- Downed teammates return when the team beats the next boss.
- Bill's Machine available since 0.8.72 with an 11-minute cooldown.
- Team leaderboard ranks by time survived.

## Public rooms

- Leader shown with a crown; an idle leader is removed after 90 s (0.8.74).
- Solo search cancels after 3 minutes idle.

## When it will not connect

- "Under maintenance / paused" is a server switch; try later.
- Strict privacy extensions can block peer-to-peer; a relay fallback exists since 0.8.32.
- A teammate shown in red is on an old client and needs a hard reload.
