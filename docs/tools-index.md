# BonkDex tools

Free browser tools on [BonkDex](https://pokebonk.info/tools/). They run on the page; no sign-up.

- [Tier list maker](https://pokebonk.info/tools/tier-list/) - drag Pokémon into tiers and share your list.
- [Build planner](https://pokebonk.info/tools/build-planner/) - sketch a run plan before you start.
- [Type chart](https://pokebonk.info/tools/type-chart/) - the standard type effectiveness table, see also [types](https://pokebonk.info/types/).
- [Randomizer](https://pokebonk.info/tools/randomizer/) - roll a random pick for challenge runs.

These are planning aids written by a fan; they do not read data from the game.
