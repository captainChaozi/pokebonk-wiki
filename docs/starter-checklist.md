# PokéBonk starter picking checklist

A short checklist I use when writing the starter pages on [BonkDex, my PokéBonk fan wiki](https://pokebonk.info/).

1. **Bulbasaur** - pick it if you want sustain; healing keeps early mistakes from ending a run.
2. **Charmander** - pick it if you like aggressive play and are comfortable dodging at low HP.
3. **Squirtle** - pick it if you want armor and a shield while you learn the maps.

Before your first run:
- Check type matchups in the [type chart](https://pokebonk.info/tools/type-chart/).
- Sketch a moveset in the [build planner](https://pokebonk.info/tools/build-planner/).
- Read the full [guides](https://pokebonk.info/guides/).
