# How to start playing PokéBonk

PokéBonk is free and runs in a web browser; there is nothing to install.

1. Open the game at pokebonk.com, or use the [play page on BonkDex](https://pokebonk.info/play/).
2. Read [how to play](https://pokebonk.info/guides/how-to-play/) and the [beginner tips](https://pokebonk.info/guides/beginner-tips/).
3. If the game will not load, see [troubleshooting](https://pokebonk.info/guides/troubleshooting/).
