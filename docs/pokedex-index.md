# BonkDex Pokédex

[BonkDex's Pokédex](https://pokebonk.info/pokedex/) has 151 pages, one per original Pokémon, for example
[Bulbasaur](https://pokebonk.info/pokedex/bulbasaur/), [Charmander](https://pokebonk.info/pokedex/charmander/) and [Squirtle](https://pokebonk.info/pokedex/squirtle/).
