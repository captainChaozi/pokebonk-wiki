# Why PokéBonk Pokédex pages skip main-series base stats (fan wiki)

Example page: [Eevee in PokéBonk](https://pokebonk.info/pokedex/eevee/) · Index: [Pokédex](https://pokebonk.info/pokedex/) · Wiki home: [pokebonk.info](https://pokebonk.info/)

## What a Pokédex page shows

- Types and family as **main-series identification references** (Eevee: Normal, #133; family Vaporeon, Jolteon, Flareon).
- PokéBonk type matchups using the game's own multipliers.

## What it deliberately leaves out

Main-series base stats, move values and evolution requirements. PokéBonk uses its own in-game stats and level-based evolution, so those numbers would mislead. Check the in-game partner card and level-up screen instead.

## PokéBonk type multipliers

| Relation | Multiplier |
|---|---|
| Super effective | x1.35 |
| Resisted | x0.8 |
| Immune | x0.5 |
| Dual types | multiply, capped at x0.4–x1.8 |

Eevee, for example, takes x1.35 from Fighting. Full grid: [type chart](https://pokebonk.info/tools/type-chart/).
