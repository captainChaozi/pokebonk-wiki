# PokéBonk FAQ (short)

Longer answers live on [the BonkDex FAQ page](https://pokebonk.info/faq/) of my fan wiki.

**What is PokéBonk?** A free, unofficial Pokémon-themed survivors-like by Charcher, played in the browser at pokebonk.com. Inspired by Megabonk.

**Is it the same as pokebonk.solais.cloud?** No, that is Touchzada's separate game with the same name.

**When is Season 2?** October 22 to November 5, 2026.

**Are there codes?** See the [codes page](https://pokebonk.info/codes/) on BonkDex for what we know.

**Where can I compare Pokémon?** The [tier list maker](https://pokebonk.info/tools/tier-list/) lets you build your own ranking.

Disclosure: I'm the developer of [BonkDex](https://pokebonk.info/), an unofficial fan wiki.
