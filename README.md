# PokéBonk Wiki (BonkDex)

**Site:** [https://pokebonk.info/](https://pokebonk.info/)

BonkDex is a fan wiki I build for **PokéBonk**, the free 3D Pokémon-themed survivor game that runs in the browser (made by Charcher, played at pokebonk.com).

Disclosure: I'm the developer of this wiki. It is an unofficial fan project and is not affiliated with or endorsed by Nintendo, The Pokémon Company, GAME FREAK, Creatures, or the game's creator.

## What's on the site
- Play PokéBonk in your browser from the [home page](https://pokebonk.info/)
- [Pokédex](https://pokebonk.info/pokedex/) with 151 entries
- [Guides](https://pokebonk.info/guides/): starters, items, bosses, beginner tips (20 guides)
- Tools: [tier list maker](https://pokebonk.info/tools/tier-list/), [build planner](https://pokebonk.info/tools/build-planner/), [type chart](https://pokebonk.info/tools/type-chart/), [randomizer](https://pokebonk.info/tools/randomizer/)
- [FAQ](https://pokebonk.info/faq/)
